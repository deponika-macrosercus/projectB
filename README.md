# 체스 이기기 연습

체스를 공부할 때 쓰는 연습 프로그램입니다. 기보를 넣고 **이겨야 하는 색**을 고르면,
그 색은 엔진(Stockfish)이 두고 반대 색(지는 쪽)은 내가 둡니다.
유리한 국면을 엔진이 실제로 어떻게 이기는지, 또 내가 얼마나 버틸 수 있는지 연습할 수 있습니다.

## 실행 방법

브라우저 보안 정책 때문에 `index.html`을 더블클릭해 직접 열면 엔진이 동작하지 않습니다.
폴더에서 간단한 로컬 서버를 띄워 주세요.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 http://localhost:8000 을 엽니다. 인터넷 연결은 필요 없습니다.

## 사용법

1. **시작 국면 만들기**: 보드에서 기물을 눌러 백·흑 수를 차례로 둡니다. 수 목록을 누르면 그 수로 돌아가고,
   거기서 다른 수를 두면 이후 수가 바뀝니다. 다른 곳의 PGN/FEN이 있으면 `텍스트로 붙여넣기`를 펼쳐서 넣을 수도 있습니다.
2. **시작 지점 선택**: ◀ ▶ (키보드 ← →)로 시작할 국면을 고릅니다. 보드에 보이는 국면에서 대국이 시작됩니다.
3. **이겨야 하는 색** 선택: 이 색을 엔진이 둡니다.
4. **엔진 설정**: 한 수당 생각 시간과 실력(0~20, 20이 최강)을 정합니다.
5. `시작`을 누르면 대국이 시작됩니다. 내 기물을 클릭한 뒤 이동할 칸을 클릭해서 둡니다.

대국 중에는 다음 기능을 쓸 수 있습니다.

- **한 수 무르기**: 내 마지막 수와 엔진의 응수를 함께 되돌립니다.
- **시작 국면부터 다시**: 고른 시작 국면으로 돌아가 다른 수비를 시도합니다.
- **보드 뒤집기**, **PGN 복사**
- 평가치는 이겨야 하는 색 기준입니다(+면 엔진이 유리, `#N`은 N수 안에 메이트).
